# DemoMed Healthcare API Assessment

Automated assessment script for analyzing patient health data and submitting results securely to the DemoMed API.

## Features
- Secure API authentication using GitHub Secrets
- Retry logic for submission errors
- Automated testing via GitHub Actions

## Setup
1. Clone this repository.
2. Add your DemoMed API key as a GitHub Secret named `DEMOMED_API_KEY`.
3. Push changes to trigger automatic workflow execution.
