# DemoMed Healthcare API Assessment

This project demonstrates API integration, data processing, and risk scoring for healthcare patient data.

## 🧩 Features
- Handles pagination, retries, and inconsistent API data
- Implements patient risk scoring (BP, temperature, age)
- Submits alert lists to the assessment API
- Saves submission feedback locally

## 🚀 Usage
```bash
pip install -r requirements.txt
python src/main.py
```
